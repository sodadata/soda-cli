Full Command Tree (WIP)

soda
  │
  │  Global flags (all commands):
  │    --output table|json|csv    # auto-detects TTY
  │    --profile <name>           # override active profile
  │    --no-color
  │    --quiet
  │    --verbose
  │    --no-interactive           # for CI/CD and AI agents
  │    --version  
  │
  ├── version                               # print version info
  │
  ├── auth
  │   ├── login   [--profile <name>]        # wizard → API key → test → save to ~/.soda/credentials
  │   ├── logout  [--profile <name>]
  │   ├── status                            # active profile, org, connection health
  │   └── switch  <profile>
  │
  ├── init                                  # scaffold soda.yml + configs/ + contracts/
  │
  ├── dashboard                             # org dashboard: datasets, results, incidents, recent jobs
  │
  ├── datasource  (alias: ds)
  │   ├── create           [--type pg|sf|bq|duck|...]   # local YAML config
  │   ├── onboard          --agent <name> --type <t>    # cloud-registered connection via Soda Agent
  │   ├── test-connection  [<name-or-file>]             # test connection
  │   ├── diagnostics      <id>                         # diagnostics warehouse config (datasource level) # TODO: what is configurable?
  │   ├── list                                          # list datasources
  │   └── delete           <id>
  │
  ├── contract
  │   ├── create    --dataset <ds/db/schema/table>
  │   │   --mode skeleton|copilot     # default: skeleton
  │   │   --output <file>
  │   │   # skeleton → bootstrap YAML from live schema (no AI, always works)
  │   │   # copilot  → full AI-generated contract (requires license)
  │   ├── lint (alias: validate)  [<file>]           # syntax check, no network (previously called validate)
  │   ├── push      [<file>]                         # push contract definition to cloud
  │   ├── pull      <identifier>                      # pull contract from cloud → local file
  │   ├── diff      [<file>]                         # local vs cloud diff (identifier read from file)
  │   ├── copilot   [<file>]  [<prompt>]  [--dataset <fqn>]
  │   │   # no args          → wizard: generate or improve?
  │   │   # file, no prompt  → wizard: what to improve?
  │   │   # --dataset only   → generate from scratch, no prompt needed
  │   │   # file + prompt    → improve existing contract
  │   │   # --no-interactive → fails with clear error describing what's missing
  │   │   --output <file>
  │   ├── verify    [<file-or-dir>]        # cloud check verification
  │   │   --datasource <file>              # explicit override when no soda.yml
  │   │   --agent                          # delegate to Soda Agent
  │   │   --push                           # run checks + push results to cloud
  │   │   --set      key=value             # runtime variable overrides
  │   │   # exit codes: 0=pass 1=checks failed 2=error 3=auth error
  │   └── proposal                         # PR flow for published contracts
  │       ├── list   [--status open|done|all]
  │       ├── pull   <id>  [--revision <n>]         # download a proposal locally
  │       ├── push   <id>  [<file>]  [--message]    # submit changes
  │       └── close  <id>  [--status done|wontdo]
  │
  ├── job  (alias: scan)
  │   ├── list
  │   │   [--datasource <id>]
  │   │   [--dataset <id>]
  │   │   [--type contract|monitor|all]
  │   │   [--status passing|failing|running|error]
  │   │
  │   │   # ID          DATASOURCE    DATASET     TYPE      STATUS     DATE
  │   │   # sc_abc123   pg_prod       orders      contract  ✗ failing  2026-03-05 08:12
  │   │   # sc_def456   pg_prod       users       monitor   ✓ passing  2026-03-05 06:45
  │   │
  │   └── logs  <id>  [--follow]
  │
  ├── results                              # contract checks + monitor alerts in one place
  │   └── list
  │       [--datasource <id>]
  │       [--dataset <id>]
  │       [--type check|monitor|all]
  │       [--status passing|failing|all]
  │       [--from <date>]
  │       [--to <date>]
  │
  │       # DATASET              TYPE     NAME                   STATUS     DATE
  │       # pg/prod/orders       check    row_count > 0          ✓ passing  2026-03-05 08:12
  │       # pg/prod/orders       check    no_nulls(order_id)     ✗ failing  2026-03-05 08:12
  │       # pg/prod/users        monitor  daily_signups anomaly  ⚠ alert    2026-03-05 06:45
  │

  │   ├── profiling    <id>                          # view cached profiling data
